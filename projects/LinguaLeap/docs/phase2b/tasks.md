## 核心设计原则

### 词汇学习能力层次模型

| 层次 | 能力 | 对应题型 |
|------|------|---------|
| L1 辨认 | 看到英文 → 认出中文 | 英译中选择 |
| L2 回忆 | 看到中文 → 想到英文 | 中译英（选择/拼写） |
| L3 运用 | 在语境中正确使用 | 填空题 |
| L4 表达 | 用英文构造完整句子 | 翻译题（中→英） |

### 年级自适应原则

```
小学（primary）  → 全选择/拖拽，零拼写压力，重在"辨认+建立连接"
初中（junior）   → 选择+输入混合，开始要求"产出"，有脚手架辅助
高中（senior）   → 输入为主，独立产出，接近真题难度
```

### 出题策略

- **全部由 AI 生成**，取消模板出题引擎
- AI 出的题自动入库（`created_by = 'ai'`）
- AI 不可用时从库里已有 AI 题中随机抽取
- 翻译题（初中/高中）答题时调 AI 实时评判

## 年级-题型矩阵

### 英译中选择（L1 辨认）

| 年级 | 题干 | 干扰项 | 答后展示 |
|------|------|--------|---------|
| 小学 | 单词 + 音标 + 发音按钮 | 明显不同类别 | 单词 + 发音 + 例句 |
| 初中 | 单词 + 音标 + 发音 | 同词性同类 | 音标 + 例句 + 用法 |
| 高中 | 单词在句子语境中 | 近义/易混淆 | 例句 + 用法辨析 |

### 中译英（L2 回忆）

| 年级 | 形式 | 辅助 | 答错后 |
|------|------|------|--------|
| 小学 | 4 选 1（英文选项+音标） | 发音按钮 | 展示正确答案 + **必须手动键入一遍** |
| 初中 | 4 选 1 + 偶尔拼写 | 发音提示 | 展示正确答案 + **必须手动键入一遍** |
| 高中 | 拼写输入，想不起来可点🔊 | 发音唤醒记忆 | 展示正确答案 + **必须手动键入一遍** |

### 填空题（L3 语境运用）

| 年级 | 形式 | 选项设计 | 答后展示 |
|------|------|---------|---------|
| 小学 | **选择填空**（选词填入句子）+ 完整中文翻译 | 2~3 个不同的词 | **对错都展示**：单词释义、为什么选这个 |
| 初中 | **形态选择填空**（同词不同形态）+ 关键词提示 | apple/apples/an apple 等 | **对错都展示**：语法规则、形态变化解析 |
| 高中 | 开放输入 + 给动词原形提示 | 无选项 | **对错都展示**：语法点、时态语态、词形变化 |

### 翻译题（L4 中→英，综合表达）

| 年级 | 形式 | 判定 | 答后展示 |
|------|------|------|---------|
| 小学 | **句子排序**（给打散的单词，排成正确句子） | 自动判定（顺序匹配） | 完整例句 + 每个单词释义 + TTS 朗读 |
| 初中 | **半填空翻译**（给句子框架，填关键词） | **AI 评判** + AI 解析 | AI 详细解析：为什么对/错 |
| 高中 | **完整翻译**（给中文，完全写英文） | **AI 评判** + AI 解析 | AI 详细解析 + 参考答案对比 |

## B.1 全 AI 出题 Prompt 重构

**目标**：重写 PromptTemplates，为每种题型 × 每个年级定制 Prompt，确保 AI 输出符合年级要求的格式。

**要点**：

1. **英译中 Prompt**（3 个年级变体）
   - 小学：干扰项用不同类别词，简单直白
   - 初中：干扰项用同词性同类词
   - 高中：题干包含语境例句，干扰项用近义/易混淆词

2. **中译英 Prompt**（3 个年级变体）
   - 小学/初中：生成 4 个英文选项
   - 高中：不生成选项，只生成 stem+answer+explanation

3. **填空题 Prompt**（3 个年级变体）
   - 小学：生成 2~3 个不同词的选项
   - 初中：生成同一词的 3~4 种形态选项（如 apple/apples/an apple/the apple）
   - 高中：不生成选项，给动词原形提示

4. **翻译题 Prompt**（3 个年级变体）
   - 小学：生成 JSON 包含正确语序 + 打散的单词列表 + 每个词的中文释义
   - 初中：生成句子框架（带空）+ 关键词答案
   - 高中：生成中文句子 + 参考英文翻译

5. **翻译评判 Prompt**（初中/高中共用）
   - 输入：原中文句子 + 参考答案 + 学生答案
   - 输出：JSON `{correct: boolean, score: 0-100, feedback: "解析"}`

**AI 返回 JSON 格式统一规范**：
```json
{
  "type": "en2zh_choice",
  "grade": "primary",
  "stem": "题干",
  "options": ["A", "B", "C", "D"],
  "answer": "正确答案",
  "explanation": "解析文本",
  "knowledgePoints": "涉及的知识点说明",
  "words": [{"word":"apple","phonetic":"/ˈæpl/","meaning":"苹果"}],
  "exampleSentence": "例句",
  "exampleZh": "例句翻译"
}
```

翻译题（小学排序）额外字段：
```json
{
  "wordOrder": ["I", "like", "apples", "."],
  "shuffledWords": ["apples", ".", "I", "like"],
  "wordMeanings": {"I":"我", "like":"喜欢", "apples":"苹果"}
}
```

**验收标准**：
- [ ] 4 种题型 × 3 个年级 = 12 套 Prompt
- [ ] 1 套翻译评判 Prompt
- [ ] 每套 Prompt 测试通过（AI 返回格式正确）

## B.2 Question 数据结构扩展

**目标**：扩展 question 表和前端数据结构，支持新的题型字段。

**数据库变更**（Flyway migration）：
```sql
ALTER TABLE question ADD COLUMN knowledge_points TEXT;  -- 知识点解析 JSON
ALTER TABLE question ADD COLUMN words TEXT;              -- 涉及的单词详情 JSON
ALTER TABLE question ADD COLUMN example_sentence TEXT;   -- 例句
ALTER TABLE question ADD COLUMN example_zh TEXT;          -- 例句翻译
ALTER TABLE question ADD COLUMN extra_data TEXT;          -- 扩展数据 JSON（排序题词序等）
ALTER TABLE question ADD COLUMN grade VARCHAR(20);        -- 适用年级
```

**说明**：
- `knowledge_points`：填空题的知识点解析（语法规则、形态变化等）
- `words`：题目涉及的单词列表 `[{word, phonetic, meaning}]`
- `extra_data`：翻译排序题的 `{wordOrder, shuffledWords, wordMeanings}`
- `grade`：标记这道题适合哪个年级

**Entity 变更**：Question 实体增加对应字段

**验收标准**：
- [ ] Flyway 迁移执行成功
- [ ] Question 实体和 Repository 更新

## B.3 AI 出题服务改造

**目标**：改造 QuestionGenerateService，实现年级感知的全 AI 出题，自动入库。

**要点**：

1. **新流程**：
   ```
   用户开始练习(bankId, type, grade, count)
     → 先查库里该年级+该题型的已有题（count 够？）
       → 够：直接抽取
       → 不够：调 AI 批量生成差额 → 入库 → 再抽取
   ```

2. **去掉模板出题引擎**：
   - QuestionService 中的 `generateEn2ZhChoice` / `generateZh2EnChoice` / `generateFillBlank` / `generateTranslate` 等模板方法标记为 @Deprecated
   - 降级时（AI 不可用 + 库里有题）从库里随机抽
   - 降级时（AI 不可用 + 库里无题）才 fallback 到模板引擎

3. **批量出题优化**：
   - 一次 API 调用生成 10 题，减少 API 消耗
   - 生成后全部自动入库

4. **年级适配**：
   - 出题时传入 grade 参数，选择对应 Prompt
   - grade 来源：题库的 grade 字段

**验收标准**：
- [ ] 开始练习时自动触发 AI 出题
- [ ] 生成的题目自动存入 question 表
- [ ] 库里有足够题时不调 AI
- [ ] AI 不可用时从库里抽已有题

## B.4 答题判定逻辑重构

**目标**：重构 PracticeService.checkAnswer()，支持各题型的差异化判定。

**判定规则**：

| 题型 | 年级 | 判定方式 |
|------|------|---------|
| 英译中选择 | 全部 | 精确匹配选项文本 |
| 中译英选择 | 小学/初中 | 精确匹配选项文本 |
| 中译英拼写 | 高中 | equalsIgnoreCase + trim |
| 填空选择 | 小学/初中 | 精确匹配选项文本 |
| 填空输入 | 高中 | 模糊匹配（容忍形态变化） |
| 翻译排序 | 小学 | 词序数组匹配 |
| 翻译半填空 | 初中 | **调 AI 评判** |
| 翻译完整 | 高中 | **调 AI 评判** |

**高中填空模糊匹配规则**：
- 完全匹配 → ✅ correct
- 忽略 s/es/ed/ing/er/est 后与 answer 词根匹配 → ⚠️ 基本正确（算对，但提示形态问题）
- 完全不匹配 → ❌

**答题 API 返回结构扩展**：
```json
{
  "correct": true,
  "partialCorrect": false,
  "correctAnswer": "apples",
  "explanation": "解析",
  "knowledgePoints": "这道题考察的知识点...",
  "words": [{...}],
  "exampleSentence": "...",
  "exampleZh": "...",
  "requireRetypeOnWrong": true,
  "aiJudgement": null
}
```

翻译题 AI 评判时：
```json
{
  "correct": true,
  "aiJudgement": {
    "score": 85,
    "feedback": "翻译基本正确。'goes to school' 用法准确...",
    "corrections": ["建议: every day 不需要大写"]
  }
}
```

**验收标准**：
- [ ] 选择题判定不变
- [ ] 高中填空支持模糊匹配
- [ ] 翻译题调 AI 评判并返回解析
- [ ] 所有题型答后返回 knowledgePoints + words

## B.5 AI 翻译评判 API

**目标**：新增 AI 评判接口，供答题时实时调用。

**API**：`POST /api/ai/judge/translate`

**请求**：
```json
{
  "stem": "他每天去上学。",
  "referenceAnswer": "He goes to school every day.",
  "userAnswer": "He go to school everyday.",
  "grade": "junior"
}
```

**处理流程**：
```
1. 构造评判 Prompt → 调 AI
2. 解析 AI 返回 → {correct, score, feedback, corrections}
3. 缓存结果（相同 stem+userAnswer 可复用）
4. AI 不可用时降级为自评模式：返回 {correct: null, feedback: "AI 暂时不可用，请自行对照参考答案"}
```

**验收标准**：
- [ ] 正确翻译判对，错误翻译给出具体反馈
- [ ] AI 不可用时降级为自评提示
- [ ] 评判结果带 score + feedback + corrections

## B.12 联调测试

**测试场景**：

1. **小学全流程**：英译中选择 → 中译英选择 → 选择填空 → 排序翻译 → 结果页
2. **初中全流程**：英译中选择 → 中译英选择 → 形态选择填空 → 半填空翻译(AI判) → 结果页
3. **高中全流程**：英译中语境选择 → 中译英拼写(+发音提示) → 开放填空 → 完整翻译(AI判) → 结果页
4. **答错 retype**：中译英答错 → 强制键入正确答案 → 才能下一题
5. **AI 降级**：断开 AI → 从库里抽题 → 翻译题降级自评
6. **TTS 验证**：各处发音按钮可用

**验收标准**：
- [ ] 场景 1~6 全部通过
- [ ] ai_call_log 记录正确
- [ ] 新字段数据完整
