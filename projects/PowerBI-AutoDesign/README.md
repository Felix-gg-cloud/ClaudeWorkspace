# PowerBI-AutoDesign

Power BI 页面设计自动化 — 讨论与实验项目

## 目标

探索 Power BI 报表页面的自动化设计方案，包括但不限于：

- 页面布局自动生成
- 视觉对象（Visual）自动配置
- 主题/样式批量应用
- 基于数据模型的智能推荐布局
- PBIX / PBIT 文件结构解析与生成

## 目录结构

```
PowerBI-AutoDesign/
├── README.md          # 项目说明
├── docs/              # 讨论笔记与方案文档
└── experiments/       # 实验代码与脚本
```
